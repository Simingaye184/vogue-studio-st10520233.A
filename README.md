# VOGUE STUDIO — Tailor-Made For Every Mbokodo

> Custom fits. Quality fabric. Confidence in every stitch.

Vogue Studio is a luxury African fashion website based in Durban, South Africa. The brand celebrates the strength and elegance of the Mbokodo (strong woman) through tailor-made dresses that blend modern couture with African heritage.

**Live Tagline:** "We dress Mbokodos 💜"
**Location:** Durban, KwaZulu-Natal, South Africa

### 📖 Project Overview & Problem Statement

Many women struggle to find dresses that fit perfectly and reflect their African identity. Retail clothing uses standard sizes that do not cater for all body types.

**This project solves this by:**
1. Offering fully custom tailoring based on exact measurements.
2. Using premium, authentic African fabrics (Shweshwe, Ankara).
3. Providing a professional online presence to attract clients and allow easy booking via WhatsApp.

### 🎯 Project Objectives

1. To design a visually appealing, culturally relevant fashion website.
2. To implement a fully responsive layout for mobile, tablet and desktop.
3. To clearly showcase services offered by Vogue Studio.
4. To provide an easy contact and booking system.
5. To establish a strong luxury brand identity.

### ✨ Key Features

- **Luxury Dark Theme:** Black gradient (#0d0d0d to #1a1a1a) with glassmorphism cards and gold #d4af37 accents and glow effects.
- **4 Fully Linked Pages:**
    - `Index.html` - Home: Hero "Tailor-Made For Every Mbokodo", features (Custom Tailoring, African Elegance, Fast Turnaround)
    - `about.html` - Our Story, Why Choose Us (Custom Fit, Premium Fabric, Mbokodo Spirit), CTA
    - `services.html` - Services: Custom Dress Tailoring, Alterations & Fittings, African Print Designs, Personal Styling
    - `contact.html` - Booking form + business info box
- **WhatsApp Integration:** Direct link to https://wa.me/27660895111 - "Chat on WhatsApp" button
- **Responsive Design:** CSS Grid and Flexbox, Media Queries for max-width 900px and 600px
- **Sticky Navigation:** Glassmorphism nav bar with backdrop-filter blur

### 🛠️ Technologies Used

- HTML5 - Structure
- CSS3 - Styling (No Frameworks - Pure CSS for learning purposes)
- Glassmorphism UI - backdrop-filter: blur()
- Flexbox & Grid - Layout
- Poppins Font - Typography

### 🚀 How To Run The Website

**No installation needed - it's a static site.**

1. Clone:
   git clone https://github.com/yourusername/vogue-studio.git
   cd vogue-studio

2. Run Locally:
      - Double-click Index.html
      - OR in VS Code: Right-click > Open with Live Server

3. Deploy for Free:
      - GitHub Pages: Settings > Pages > Deploy from main branch
      - Netlify: Drag and drop folder

### 🎨 Design System

- Background: linear-gradient(180deg, #0d0d0d 0%, #1a1a1a 100%)
- Gold Accent: #d4af37 - Luxury, Royalty
- Text: #e0e0e0 (light) / #a0a0a0 (muted)
- Cards: rgba(30,30,30,0.6) + blur 12px
- Buttons: Gold, pill shape border-radius 50px, box-shadow glow
- Brand Voice: Empowering, African, Luxurious
